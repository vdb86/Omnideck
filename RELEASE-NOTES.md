# Release notes

What changed in each version of [Omnideck](https://play.google.com/store/apps/details?id=com.omnideck.app), newest first. The same text as the app's What's new page.

## 3.4

- More floating buttons (Pro): add up to four more buttons, each with its own look, position, gestures, Action wheel and settings. A new button starts with Button 1's look, next to it.
- Show app names (Pro): names under the icons in the Deck, on one or two lines and in the size you choose, per Deck. Folders can now be named too (Edit on a folder in edit mode).
- Add action never lets you pick more than fits on the page. When it is full, add a row or a column right there and keep adding (Pro).
- Vibrate when a swipe runs (Pro): a new switch for edge swipes, per edge pair.
- Edge swipe with only one edge on: its gestures and Action wheel are now that edge's own - adding apps to the right wheel no longer puts them on the left one too.
- The album cover on the floating button now follows track changes again, also when the button was hidden or the phone was just unlocked.
- Making a page's grid bigger (Add action, the page manager or the default rows / columns) no longer rearranges its icons, folders or widgets - you just get the new empty row or column.
- Several Pro features are now free, including Backup & restore, home-screen icons and Deck position.

## 3.3

- Multiple Decks (Pro): up to five Decks, each with its own pages. Decks 2-5 use Deck 1's settings until you change one for that Deck. Any Open Deck gesture or wheel slot chooses which Deck it opens.
- Edge swipe pairs (Pro): add up to four more left/right pairs of edge strips, each with its own touch areas, gestures, Action wheel and settings.
- The Triggers tab is split into Button, Edge swipe and Icons, and Swipe-through and Automatic behaviour are now set separately for the button and for each edge pair. Edge strips can also hide in landscape and let touches through in fullscreen apps.
- Launcher icons for every Deck (Pro): each Deck can have its own left and right home-screen icon, and any icon can show / hide its Deck instead of only opening it.
- Lock position (Pro): a new switch in Deck position stops the Deck from being picked up and moved by accident, also when it is pinned.

## 3.2

- Edge swipe: give each strip its own touch area (position and width), and tap a strip to run an action or open the Action wheel. The Action wheel can also open at a fixed spot instead of where you touch, and has a new Opacity setting.
- A floating button snapped to the bottom edge now stays above the navigation bar instead of behind it.

## 3.1

- New Web search action: type a search with the keyboard already open, pick from your recent searches or the search engine's suggestions as you type, and the results open in your browser. Choose the engine per action - Google, DuckDuckGo, Bing, Brave Search, Ecosia, Qwant, Yahoo, Naver, Yandex, Seznam or Baidu - with a default in Settings > General, and pick the browser per action too. Typing a web address offers to open it directly.

## 3.0

- New HTTP tab in Add action: save web requests and Wake-on-LAN packets, then run them from the Deck, a gesture or the Action wheel. Import a cURL command, test before saving, and show the result as a toast, notification, dialog or full-screen window.
- HTTP requests can use variables: write {{name}} to put in a fixed value, to be asked for a text, number, password, date, time, colour or a choice when the request runs, or to switch between values on each run.
- Websites can fetch the site's own icon.
- New Library in Settings > General: edit, duplicate or delete your saved texts, HTTP requests and websites without going through Add action.
- Edge swipe: give each strip its own actions, or let both share one set with Mirror, for directional gestures and the Action wheel.
- Per-app trigger rules can now pick any installed app, system apps included.
- Restore now checks the file before touching anything: a file from another app, or from a newer Omnideck, is refused and your settings stay as they were.
- Bottom notifications can now run Omnideck actions from its gestures: pick any Omnideck action there, give it a name and an icon, and Omnideck runs it.
- Contact actions now find the same person after a restore or on a new phone.
- Uses much less memory while running in the background.

## 2.9.1

## 2.9

- Added the Action wheel: swipe from the floating button or a screen edge to open a wheel of actions around your finger, slide onto one and lift to run it.
- Set up the wheel in its own editor: pick actions, icons and names, and long press an action to move it.
- Save texts in the new Text tab of Add action and paste them into the field you're typing in, from the Deck, a gesture or the Action wheel.
- The floating button can show the cover of what's playing, or an animation: Record, Tape, CD, Equalizer, Pulse, Notes, Wave or Ticker.
- The floating button now animates when it shows and hides, with the same 36 animations as the Deck and its own speed.
- Add action now marks the activities other apps can't open, and a Test button tries an activity or intent before you add it.
- "Button gestures" and "Directional swipes" are now both called Directional gestures.
- Swipe-through launch and long swipes now work together: slow down between the short and the long distance to open the Deck, or keep going and stop to run the long action.
- Long swipes respond faster: a slow swipe runs the long action as soon as you stop.
- The icon under your finger is highlighted more clearly during swipe-through.
- The Deck no longer closes by itself while your finger is still sliding over it.
- Swipe-through launch moved to the Triggers tab.
